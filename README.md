# Aabhushan Sales Shopify Theme

Manufacturer of micro imitation jewellery.

This branch contains a Malabar-inspired Shopify catalogue redesign for Aabhushan Sales. Connect the `codex/aabhushan-renovation` branch in Shopify Admin under `Online Store > Themes > Add theme > Connect from GitHub`.

After connecting, preview the theme first. Fill theme settings for logo, phone, WhatsApp, store hours, Google Maps URL, social links, homepage imagery, and featured collection.

Safe positioning note: this theme avoids claims such as BIS/HUID gold, certified diamonds, buyback, gold rate, and lifetime maintenance unless those services are officially confirmed by Aabhushan Sales.
