# Aabhushan Sales Shopify Theme

Manufacturer of micro imitation jewellery.

This branch contains a Shopify Online Store theme for the Aabhushan Sales renovation. Connect the `codex/aabhushan-renovation` branch in Shopify Admin under `Online Store > Themes > Add theme > Connect from GitHub`.

After connecting, open the Shopify theme customizer and fill the theme settings for logo, phone, WhatsApp, store hours, Google Maps URL, and social links.
