# Aabhushan Sales Vercel v0 Motion Prototype

This is a Vercel-ready Next.js prototype for Aabhushan Sales with a v0-style component layout and Framer Motion animations.

## Stack

- Next.js App Router
- Tailwind CSS
- Framer Motion
- Lucide icons

## Run Locally

```bash
npm install
npm run dev
```

## Deploy On Vercel

Import this project in Vercel and keep the root directory as:

```text
vercel-v0-motion
```
